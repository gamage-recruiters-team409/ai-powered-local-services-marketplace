# AI-Powered Local Services Marketplace

Development repository for the Gamage Recruiters AI-Powered Local Services Marketplace.

## Project Overview

The platform connects customers with independent and business service providers through a structured digital marketplace.

The system supports service discovery, provider verification, listings, booking, scheduling, messaging, payments, service completion, reviews, disputes, provider earnings, payouts, administration, analytics, notifications, and selected AI-assisted functionality.

## Architecture

The backend follows a layered modular-monolith architecture with clear functional module boundaries.

Main architectural areas include:

- Presentation
- API
- Security
- Service / Domain
- Integration
- Persistence
- Data

## Main Branches

- `main` – stable and release-ready code
- `develop` – main development integration branch

Normal development work must be completed through short-lived feature or fix branches and merged through reviewed pull requests.

## Development Rule

Developers must not push directly to `main` or `develop`.

All development must follow the approved project baseline, module ownership rules, GitHub workflow, and pull-request review process.
